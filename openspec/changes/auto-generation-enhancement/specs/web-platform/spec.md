# Web Platform Spec (增量)

此文档记录对 web-platform 功能的增量修改。

## 修改需求

### 需求: 查看单条记录详情
系统必须显示完整的记录信息，并实时展示生成任务的状态和结果。

#### 场景: 查看单条记录详情（原有需求）
- **当** 用户点击"查看详情"链接
- **那么** 系统必须跳转到详情页 `/public/:id`
- **并且** 必须显示完整的记录信息：
  - 高清渲染图（可点击放大）
  - 完整的社媒摘要
  - 详细汇总（可折叠）
  - 原始对话（可折叠）
  - 元数据（平台、模型、时间）
- **并且** 必须提供"返回列表"按钮

#### 场景: 详情页自动加载生成状态（新增）
- **当** 用户进入对话详情页
- **那么** 系统必须立即调用 GET /api/conversations/:id/status 获取生成任务状态
- **并且** 必须显示所有进行中或未完成的任务的状态提示
- **并且** 必须每隔 2 秒轮询一次状态直到所有任务完成

#### 场景: 详情页展示生成结果（新增）
- **当** 生成任务状态为 completed
- **那么** 详情页必须自动显示生成的内容：
  - 社交媒体摘要：显示在"社媒摘要"区域
  - 详细汇总：显示在"详细汇总"区域
  - 渲染图片：显示在新增的图片展示区域
- **并且** 必须替换掉之前的"生成中..."提示
- **并且** 必须停止该任务的轮询

#### 场景: 详情页显示生成失败（新增）
- **当** 生成任务状态为 failed
- **那么** 详情页必须在对应区域显示错误信息
- **并且** 必须提供"重试"按钮
- **并且** 错误信息必须包含失败原因

### 需求: 详情页必须提供图片展示功能
系统必须在详情页提供专门的图片展示区域，展示所有已渲染的图片。

#### 场景: 显示图片展示区域（新增）
- **当** 用户进入对话详情页
- **并且** 该对话有已渲染的图片（image_urls 不为空）
- **那么** 系统必须在"原始对话"区域上方显示图片展示区域
- **并且** 必须按渲染时间倒序显示所有图片
- **并且** 每张图片必须显示其模板类型标签

#### 场景: 图片预览功能（新增）
- **当** 用户点击图片展示区域的任意图片
- **那么** 系统必须打开图片预览模态框
- **并且** 模态框必须以最大尺寸显示图片
- **并且** 用户可以通过点击背景、按 ESC 键或点击关闭按钮关闭预览

#### 场景: 无图片时的占位（新增）
- **当** 用户进入对话详情页
- **并且** 该对话没有已渲染的图片
- **那么** 图片展示区域必须显示占位提示"暂无渲染图片"
- **并且** 必须提供快捷渲染按钮

### 需求: 详情页必须提供重新生成功能
系统必须允许用户在详情页重新生成各类内容。

#### 场景: 重新生成按钮（新增）
- **当** 用户在详情页
- **那么** 系统必须提供以下生成按钮：
  - "📝 重新生成详细汇总"
  - "📱 重新生成社媒摘要"
  - "🎨 重新生成 Bento UI"
  - "📧 重新生成 Newsletter"
  - "✉️ 重新生成 Retro Letter"

#### 场景: 点击重新生成按钮（新增）
- **当** 用户点击任意重新生成按钮
- **那么** 系统必须立即创建新的生成任务
- **并且** 必须禁用该按钮并显示"生成中..."
- **并且** 必须开始轮询任务状态
- **并且** 任务完成后必须自动更新对应内容

#### 场景: 重新生成进行中禁止重复点击（新增）
- **当** 生成任务正在进行中
- **那么** 对应的生成按钮必须禁用
- **并且** 按钮必须显示"生成中..."文本
- **并且** 必须忽略用户对该按钮的重复点击

#### 场景: 重新生成完成（新增）
- **当** 重新生成任务完成
- **那么** 系统必须自动更新界面的对应内容
- **并且** 对于 AI 内容，必须替换旧内容
- **并且** 对于图片，必须将新图片添加到图片展示区域的最前面
- **并且** 按钮状态必须恢复为可用
- **并且** 必须显示"生成完成"提示（持续 3 秒）
