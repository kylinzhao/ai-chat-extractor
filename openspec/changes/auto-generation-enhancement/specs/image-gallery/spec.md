# Spec: 图片展示

此规范定义详情页如何展示已渲染的图片。

## 新增需求

### 需求: 图片展示区域
详情页必须包含一个专门的图片展示区域，用于显示所有已渲染的图片。

#### 场景: 显示所有已渲染的图片
- **当** 用户进入对话详情页
- **并且** 该对话有已渲染的图片（image_urls 不为空）
- **那么** 系统必须在图片展示区域显示所有图片
- **并且** 每张图片必须按渲染时间倒序排列（最新的在前）
- **并且** 每张图片必须显示其模板类型标签（Bento UI、Newsletter 或 Retro Letter）

#### 场景: 无图片时的占位
- **当** 用户进入对话详情页
- **并且** 该对话没有已渲染的图片
- **那么** 图片展示区域必须显示占位提示"暂无渲染图片，点击下方按钮生成"
- **并且** 占位区域必须提供快捷生成按钮

### 需求: 图片预览功能
系统必须支持图片的放大预览功能。

#### 场景: 点击图片放大
- **当** 用户点击图片展示区域的任意图片
- **那么** 系统必须打开图片预览模态框
- **并且** 模态框必须以最大尺寸显示图片
- **并且** 模态框背景必须为半透明黑色遮罩

#### 场景: 关闭预览
- **当** 图片预览模态框打开时
- **那么** 用户必须可以通过以下方式关闭预览：
  - 点击模态框背景区域
  - 按 ESC 键
  - 点击关闭按钮
- **并且** 关闭后必须返回到详情页

#### 场景: 切换图片预览
- **当** 图片预览模态框打开时
- **并且** 有多张图片
- **那么** 模态框必须提供左右切换按钮
- **并且** 用户可以通过点击切换按钮浏览所有图片

### 需求: 图片加载优化
系统必须优化图片加载体验。

#### 场景: 图片懒加载
- **当** 图片展示区域包含多张图片
- **那么** 系统必须实现懒加载或使用渐进式加载
- **并且** 首屏图片必须在 2 秒内开始显示
- **并且** 必须显示加载指示器直到图片加载完成

#### 场景: 图片加载失败
- **当** 图片加载失败（URL 无效或网络错误）
- **那么** 系统必须显示图片加载失败的占位图
- **并且** 占位图必须显示"图片加载失败"提示
- **并且** 必须提供"重新渲染"按钮

### 需求: 图片操作
系统必须提供图片的常用操作功能。

#### 场景: 下载图片
- **当** 用户将鼠标悬停在图片上（桌面端）
- **那么** 系统必须显示图片操作工具栏
- **并且** 工具栏必须包含"下载"按钮
- **并且** 点击"下载"按钮必须下载图片到本地

#### 场景: 复制图片
- **当** 用户点击图片操作工具栏的"复制"按钮
- **那么** 系统必须将图片复制到剪贴板
- **并且** 必须显示"已复制"提示信息

#### 场景: 新图片自动添加
- **当** 新的图片渲染任务完成
- **那么** 系统必须自动将新图片添加到图片展示区域
- **并且** 新图片必须显示在最前面
- **并且** 必须显示"新图片"高亮提示（持续 3 秒）
