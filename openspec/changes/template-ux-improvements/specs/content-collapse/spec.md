# 内容折叠功能规范

## 新增需求

### 需求:汇总信息默认收起
系统必须在对话详情页将 detailed_summary 默认设置为收起状态。

#### 场景:首次加载对话详情页
- **当** 用户访问对话详情页
- **那么** detailed_summary 必须默认处于收起状态

#### 场景:收起状态显示内容
- **当** detailed_summary 处于收起状态
- **那么** 系统必须显示前 100 个字符 + "展开"按钮

---

### 需求:折叠/展开交互
系统必须提供平滑的折叠和展开交互体验。

#### 场景:点击展开按钮
- **当** 用户点击"展开"按钮
- **那么** 系统必须显示完整的 detailed_summary 内容
- **并且** 按钮文本变为"收起"

#### 场景:点击收起按钮
- **当** 用户点击"收起"按钮
- **那么** 系统必须恢复到收起状态（显示前 100 字符）
- **并且** 按钮文本变为"展开"

#### 场景:展开/收起动画
- **当** 用户切换展开/收起状态
- **那么** 系统必须使用平滑的 CSS 动画（transition）

---

### 需求:折叠状态记忆
系统必须记住用户的折叠/展开选择。

#### 场景:导航后保持状态
- **当** 用户展开 detailed_summary 后导航到其他页面再返回
- **那么** 系统必须保持展开状态

#### 场景:刷新后恢复默认
- **当** 用户刷新页面
- **那么** 系统必须恢复到默认的收起状态

---

### 需求:内容截断处理
系统必须智能截断内容，避免在句子中间截断。

#### 场景:在句子边界截断
- **当** 前 100 字符正好在句子中间
- **那么** 系统必须在最近的句号、问号或感叹号处截断

#### 场景:无句子边界时截断
- **当** 前 100 字符内没有句子结束标点
- **那么** 系统必须在第 100 字符处截断并添加省略号（...）

---

### 需求:Markdown 格式支持
系统必须在折叠状态下正确处理 Markdown 格式。

#### 场景:折叠状态显示 Markdown
- **当** detailed_summary 包含 Markdown 格式且处于折叠状态
- **那么** 系统必须正确渲染前 100 字符的 Markdown 格式

#### 场景:展开状态显示 Markdown
- **当** 用户展开 detailed_summary
- **那么** 系统必须完整渲染所有 Markdown 格式

---

### 需求:性能要求
系统必须确保折叠功能不影响页面性能。

#### 场景:长文本折叠
- **当** detailed_summary 超过 5000 字符
- **那么** 折叠/展开动画时间不得超过 300ms

#### 场景:快速切换
- **当** 用户快速连续点击展开/收起
- **那么** 系统必须使用防抖机制，避免动画冲突
