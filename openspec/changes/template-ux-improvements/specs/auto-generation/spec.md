# 自动生成流程规范

## 修改需求

### 需求:调整任务触发顺序
自动生成流程必须确保 AI 任务在渲染任务之前完成。

#### 场景:AI 任务先执行
- **当** 触发自动生成
- **那么** 系统必须先触发 AI 任务（social_media_summary、detailed_summary、title）
- **并且** 渲染任务必须等待 AI 任务完成后再触发

#### 场景:AI 完成后触发渲染
- **当** 所有 AI 任务完成
- **那么** 系统必须自动触发所有模板的渲染任务

---

### 需求:实现任务依赖检查
自动生成流程必须检查任务依赖关系。

#### 场景:添加渲染任务时记录依赖
- **当** 系统添加渲染任务到队列
- **那么** 必须记录该任务依赖对应的 AI 任务

#### 场景:执行前检查依赖
- **当** 渲染任务准备执行
- **那么** 必须检查依赖的 AI 任务是否已完成

---

### 需求:改进错误处理
自动生成流程必须改进错误处理和重试逻辑。

#### 场景:AI 任务失败时
- **当** AI 任务失败或超时
- **那么** 系统必须记录错误日志
- **并且** 不触发渲染任务或标记渲染任务为失败

#### 场景:渲染任务失败时
- **当** 渲染任务失败
- **那么** 系统必须重试最多 3 次
- **并且** 记录失败原因

#### 场景:部分失败时继续
- **当** 某个模板渲染失败
- **那么** 系统必须继续渲染其他模板
- **并且** 在前端显示部分成功状态

---

### 需求:生成所有模板
自动生成流程必须为所有可用模板生成图片。

#### 场景:生成四种模板
- **当** 触发自动生成
- **那么** 系统必须为以下模板生成图片：Bento UI、Newsletter、Retro Letter、XiaoHongShu

#### 场景:模板生成顺序
- **当** 触发多个模板渲染
- **那么** 渲染任务必须按添加顺序依次执行

---

### 需求:状态更新机制
自动生成流程必须正确更新对话状态。

#### 场景:所有任务完成时更新状态
- **当** AI 任务和所有渲染任务完成
- **那么** 系统必须更新 conversation.status 为 'completed'

#### 场景:部分失败时更新状态
- **当** 部分任务失败但有至少一个任务成功
- **那么** 系统必须更新状态为 'completed'（部分成功也算完成）

#### 场景:所有任务失败时更新状态
- **当** 所有任务都失败
- **那么** 系统必须保持 status 为 'processing' 或更新为 'failed'
