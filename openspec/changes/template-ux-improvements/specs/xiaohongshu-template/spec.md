# 小红书模板规范

## 修改需求

### 需求:小红书模板边距优化
小红书模板必须减少内边距以提高内容区域利用率。

#### 场景:卡片内边距
- **当** 渲染小红书风格图片
- **那么** 卡片内边距（padding）必须从 40px 减少到 10px

#### 场景:保持视觉平衡
- **当** 减少内边距后
- **那么** 系统必须确保文字不会贴边，保持可读性

---

### 需求:使用 AI 生成的标题
小红书模板必须使用 AI 生成的 title 作为图片标题，而不是硬编码的"AI对话摘要"。

#### 场景:显示 AI 标题
- **当** 生成小红书风格图片且 title 字段存在
- **那么** 图片标题必须显示 AI 生成的 title

#### 场景:title 为空时回退
- **当** title 字段为空或 null
- **那么** 图片标题必须显示默认格式"AI 对话摘要 #ID"

---

### 需求:支持 Markdown 格式渲染
小红书模板必须正确渲染 Markdown 格式的摘要内容。

#### 场景:渲染 Markdown 加粗
- **当** 摘要包含 Markdown 加粗标记
- **那么** 图片中必须显示为粗体文本

#### 场景:渲染 Markdown 列表
- **当** 摘要包含 Markdown 列表
- **那么** 图片中必须正确显示为列表格式

#### 场景:渲染 Markdown 代码块
- **当** 摘要包含 Markdown 代码块
- **那么** 图片中必须显示为带背景的代码块

#### 场景:Markdown 渲染失败时回退
- **当** Markdown 格式不正确或解析失败
- **那么** 图片必须显示纯文本内容

---

### 需求:保持视觉设计一致性
小红书模板必须在优化后保持原有的视觉设计风格。

#### 场景:保持渐变背景
- **当** 渲染小红书风格图片
- **那么** 背景必须保持橙红色渐变（#FF6B6B → #FF8E53 → #FFA726）

#### 场景:保持卡片样式
- **当** 渲染小红书风格图片
- **那么** 卡片必须保持白色背景、圆角 20px、阴影效果

#### 场景:保持标签系统
- **当** 渲染小红书风格图片
- **那么** 底部标签必须保持原样式（浅灰背景、圆角 12px）
