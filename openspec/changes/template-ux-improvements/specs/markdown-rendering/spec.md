# Markdown 渲染规范

## 新增需求

### 需求:前端渲染 Markdown 格式
系统必须在前端组件中正确解析和渲染 Markdown 格式的文本内容。

#### 场景:渲染加粗文本
- **当** AI 生成的摘要包含 Markdown 加粗标记（`**text**`）
- **那么** 前端必须显示为粗体文本

#### 场景:渲染列表
- **当** AI 生成的摘要包含 Markdown 无序列表
- **那么** 前端必须正确显示为项目符号列表

#### 场景:渲染代码块
- **当** AI 生成的摘要包含 Markdown 代码块（```code```）
- **那么** 前端必须显示为代码块，带有语法高亮

#### 场景:渲染链接
- **当** AI 生成的摘要包含 Markdown 链接（`[text](url)`）
- **那么** 前端必须渲染为可点击的链接

#### 场景:渲染换行
- **当** AI 生成的摘要包含换行符
- **那么** 前端必须正确渲染为段落换行

#### 场景:Markdown 格式错误时回退
- **当** Markdown 解析失败或格式不正确
- **那么** 系统必须回退到显示纯文本，不抛出错误

---

### 需求:图片模板渲染 Markdown 格式
系统必须在所有图片模板（Bento UI、Newsletter、Retro Letter、XiaoHongShu）中渲染 Markdown 格式。

#### 场景:小红书模板渲染 Markdown
- **当** 生成小红书风格图片且摘要包含 Markdown 格式
- **那么** 图片中必须正确渲染格式（加粗、列表等）

#### 场景:Bento UI 模板渲染 Markdown
- **当** 生成 Bento UI 图片且摘要包含 Markdown 格式
- **那么** 图片中必须正确渲染格式

#### 场景:图片渲染支持 HTML 转义
- **当** Markdown 内容包含特殊字符（<, >, &, "）
- **那么** 图片渲染器必须先进行 HTML 转义再渲染

---

### 需求:Markdown 渲染性能
系统必须确保 Markdown 渲染不影响页面性能。

#### 场景:长文本渲染
- **当** 摘要文本超过 1000 字符
- **那么** 渲染时间不得超过 100ms

#### 场景:复杂格式渲染
- **当** 摘要包含多个嵌套格式（如列表中的代码块）
- **那么** 渲染时间不得超过 200ms

---

### 需求:Markdown 渲染安全性
系统必须防止 XSS 攻击和恶意代码注入。

#### 场景:过滤危险 HTML
- **当** Markdown 内容包含 HTML 标签（<script>、<iframe> 等）
- **那么** 系统必须过滤或转义这些标签

#### 场景:过滤危险链接
- **当** Markdown 内容包含 javascript: 链接
- **那么** 系统必须移除或禁用这些链接
