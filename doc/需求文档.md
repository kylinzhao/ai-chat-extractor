# AI 聊天内容萃取与分发专家 (AI-Chat Extractor) 需求文档

## 1. 产品概述
### 1.1 定位
一个跨平台的 AI 对话管理工具，支持从主流大模型（Gemini、豆包）采集原始对话，利用高性价比模型（DeepSeek）进行深度加工与“去 AI 化”总结，并通过 Puppeteer 渲染生成专业感十足的社交媒体分享图，最后实现自动化网页归档与管理。

### 1.2 核心价值
- **打破数据孤岛**：统一管理不同平台的碎片化对话。
- **内容二次创作**：将原始对话快速转化为结构化的笔记和社交媒体内容。
- **视觉化分发**：提供专业级模板，降低分享成本。

---

## 2. 功能模块设计

### 2.1 浏览器插件 (采集端)
- **目标平台**：Gemini (Web), 豆包 (Web)。
- **触发逻辑**：手动触发。在聊天页面注入悬浮按钮或通过插件 Popup 触发。
- **抓取能力**：
  - **文本流**：完整抓取 User 与 Assistant 的对话内容，保持上下文层级。
  - **多媒体**：识别并捕获对话中的图片（保存 URL 或转存）。
  - **元数据**：自动记录当前平台名称（Gemini/Doubao）、模型版本、抓取时间。
- **发送机制**：将捕获的数据以 JSON 格式 POST 发送至后端 API。

### 2.2 后端处理引擎 (加工端)
- **核心逻辑**：一个原始对话对应一个 `Summary_Group`。
- **AI 加工 (基于 DeepSeek API)**：
  - **详细汇总**：提炼逻辑、要点、知识点，适用于笔记管理软件。
  - **社媒摘要**：采用“活人味”提示词，生成短小精悍、具分享欲的文案。
- **视觉渲染 (Puppeteer)**：
  - 将生成的社媒摘要填充至 HTML 模板。
  - 后端启动 Headless Chrome 进行 @2x 高清截图。
  - **内置模板**：
    - **Bento UI**：现代化卡片布局，专业且具科技感。
    - **Newsletter**：模拟专业订阅邮件，排版克制。
    - **复古信纸**：模拟物理质感，适合感性思考分享。

### 2.3 Web 管理与展示 (归档端)
- **公开展示页**：瀑布流或列表展示已公开的内容（包含原始对话、总结、分享图）。
- **管理后台 (Secret Access)**：
  - 采用 **固定密钥 URL** 访问（如 `/admin-secure-path-123`），无需账户体系。
  - **状态管理**：一键切换每条记录的“公开/隐藏”。
  - **内容微调**：支持手动修改 AI 生成的总结和摘要。
  - **删除记录**：对过期或隐私内容进行物理删除。

---

## 3. 核心提示词 (Prompt) 策略
为确保生成的内容“有活味”，预置以下 Prompt 逻辑：
- **去 AI 化指令**：要求避开“总之、综上所述、首先/其次”等词汇。
- **角色设定**：模拟资深博主或技术专家在朋友圈、即刻等平台的日常分享风格。
- **简洁性**：强行限制字数，突出金句和核心结论。

---

## 4. 技术栈推荐
- **插件**：Chrome Extension Manifest V3 (Vanilla JS / Vue3)。
- **后端**：Node.js (Fastify 或 Koa) —— 匹配 Puppeteer 的生态。
- **模型**：DeepSeek-V3 / R1 API (国产性价比之王)。
- **数据库**：SQLite (轻量快捷) 或 MongoDB (灵活存储长文本)。
- **图片渲染**：Puppeteer (后端 HTML 转图片)。
- **部署**：云服务器（建议具备海外访问能力以兼顾 Gemini 访问）。

---

## 5. 项目路线图 (Roadmap)
- **第一阶段 (MVP)**：完成插件抓取逻辑，接入 DeepSeek 生成基础总结。
- **第二阶段 (Visual)**：集成 Puppeteer，上线至少 2 款专业分享模板。
- **第三阶段 (Archive)**：上线 Web 管理页面，支持内容公开/隐藏控制。
- **第四阶段 (Integration)**：预留对 NotebookLM 或 Notion 等工具的导出接口。
